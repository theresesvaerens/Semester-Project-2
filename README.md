# Semester-Project-2
MODO – Student Auction Marketplace
MODO is an online auction marketplace created for Noroff students. The platform allows students to buy and sell items through an auction-based system using credits.

The project was developed as part of a Noroff Front-End Development semester project.

## Live Demo
https://tssp2.netlify.app/index.html


## Features
### Public features
- Browse available auction listings.
- Search listings by title and description.
- Filter listings by category.
- View individual listing details.
- View bidding history.
- Browse the marketplace without creating an account.

### Registered student features
- Register using a Noroff student email address (`@stud.noroff.no`).
- Log in and log out.
- View and edit a personal profile.
- Add a profile bio, avatar and banner image.
- View available credits.
- Create new auction listings.
- Edit and delete your own listings.
- Place bids on other students' listings.
- View listings you have created.
- View listings you have placed bids on.

## API
MODO uses the Noroff Auction API v2 for authentication, profiles, listings and bidding.
API base URL:

`https://v2.api.noroff.dev`


## Design
MODO follows a minimal and modern visual identity inspired by Scandinavian design.

The design focuses on:
- Clean layouts and simple navigation.
- Neutral, warm colours.
- Clear typography.
- Consistent components.
- A responsive layout for different screen sizes.

The main colour palette includes charcoal, warm white, sand and sage.
